Tentang Saya

Latar Belakang & Pendekatan

Saya adalah lulusan D3 Teknik Informatika yang berfokus pada Frontend Development dan rekayasa perangkat lunak web. Selama masa studi dan pengerjaan berbagai proyek, saya terbiasa membangun antarmuka web yang terstruktur, responsif, dan mudah digunakan, sembari memahami bagaimana sistem backend dan basis data bekerja di balik layar.

Dalam pengembangan aplikasi, saya menggunakan React (JSX) untuk antarmuka pengguna, serta memiliki pemahaman pada sisi backend dan manipulasi basis data menggunakan PHP, Python, MySQL, dan PostgreSQL. Saya senang menyelesaikan tantangan teknis seputar integrasi antarmuka dengan alur data yang kompleks—seperti pengolahan input pengguna, visualisasi alur turnamen, hingga integrasi antarmuka dengan sistem pemrosesan cerdas (NLP).

Overview & Masalah:

Pencatatan data komoditas pangan oleh admin di lapangan sering memakan waktu jika dilakukan manual, sementara masyarakat membutuhkan perbandingan harga antar-pasar yang transparan dan estimasi anggaran belanja harian yang akurat.

Solusi & Fitur yang Dikembangkan:

  • Admin Portal: Login terproteksi dan input data menggunakan rekaman suara / file audio dengan AI NLP untuk parsing data langsung ke MySQL.

  • Transparansi Pasar: Fitur pembanding harga komoditas pangan antar-pasar, direktori kios, dan katalog produk.
